# Heyday Hair Studio & Nail Bar

## Files
- `index.html`
- `css/styles.css`
- `js/script.js`

## Upload to hosting
### GitHub Pages
1. Upload all files and folders to your repository root.
2. Make sure `index.html` stays in the main root.
3. Commit and push.
4. Enable GitHub Pages in repository settings.

### cPanel / regular hosting
1. Open `public_html`.
2. Upload the contents of this folder.
3. Keep the `css` and `js` folders in the same structure.

## Main features
- Mobile-first layout
- Direct call buttons
- Direct WhatsApp button
- Sticky mobile action bar
- Separate HTML, CSS, and JS files
